# VideoUniq Pro

Пакетная уникализация видео без нейросетей и визуальный редактор (CapCut-стиль). Windows 10/11 x64 (портативная папка) и Linux для разработки.

Стек: Python 3.11+, PySide6, FFmpeg/FFprobe (libmpv по возможности, иначе Qt Multimedia / кадры FFmpeg). Версия: **2.0.0**.

## Запуск на Linux (демо / разработка)

```bash
python3 -m pip install -r requirements.txt
PYTHONPATH=src python -m videouniq
```

Нужны `ffmpeg` и `ffprobe` в PATH (на Ubuntu: `sudo apt install ffmpeg`).

## Что умеет V2

- Сайдбар: **Видеоредактор**, Уникализатор, История и загрузки, Настройки рендера, Пресеты метаданных, Логи.
- Четыре зоны редактора: медиа+текст, плеер/холст, инспектор, магнитная видеодорожка и несколько текстовых.
- Cut/trim/split (`Ctrl+B`), магнитное закрытие дыр, перестановка клипов, кроссфейд / уход в чёрный 0.2–1.5 с, громкость 0–200% и mute.
- Текст: системные и свои шрифты, обводка, плашка TikTok, тень, длительность на таймлайне, сдвиг ±15 px на уникализированных копиях.
- Плеер: пробел, стрелки по кадрам, кадр 9:16 / 16:9 / 1:1 / original; перетаскивание, масштаб и поворот текста с направляющими.
- Проекты `.vup`: `Ctrl+S` / `Ctrl+O`, автосохранение раз в 60 с, пресеты стиля текста.
- Уникализатор принимает проект с бейджем «Проект», кнопка «В редактор». Один проход FFmpeg: монтажный граф + уникализация (без двойного энкода). Опция чистого `master.mp4`.
- Экспорт одного чистого ролика из редактора, отправка в уникализатор на 5 копий, ZIP готовых копий. Очистка кэша в настройках.

Уникализатор v1 не переписывался: те же пресеты Лайт / Оптимальный / Жёсткий / Ручной.

## Windows — портативная сборка

Распакуйте zip на рабочий стол и запустите `VideoUniqPro.bat`. Внутри уже лежат Python, PySide6 и FFmpeg. Интернет не нужен.

## Сборка Windows zip с Linux

```bash
python3 scripts/build_windows_portable.py
```

Результат: `dist/VideoUniqPro-windows-x64.zip`.
